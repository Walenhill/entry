# Руководство по участию в разработке (Contributing)

Спасибо за интерес к проекту! Мы приветствуем любые улучшения, исправления ошибок и предложения новых функций.

## Как внести вклад

1. **Форкните репозиторий** и создайте новую ветку для ваших изменений:
   ```bash
   git checkout -b feature/ваша-фича
   ```
2. **Локальный запуск и проверка**:
   Проект запускается одной командой через Docker:
   ```bash
   ./start.sh   # Linux / macOS
   start.bat    # Windows
   ```
   Убедитесь, что все тесты в `backend/tests/` проходят успешно.

3. **Создайте Pull Request**:
   * Опишите, какие изменения были внесены и зачем.
   * Убедитесь, что код чистый, понятный и не ломает существующий функционал.
   * Автоматические тесты и проверки проанализируют ваш PR.

## Сообщения об ошибках

Если вы обнаружили баг, пожалуйста, создайте [Issue](https://github.com/Walenhill/entry/issues) с подробным описанием:
* Шаги для воспроизведения проблемы.
* Ожидаемое и фактическое поведение.
* Ваше окружение (ОС, версия Docker/браузера).
