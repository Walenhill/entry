## Reporting a Vulnerability

We take the security of this project seriously. Automated security monitoring and vulnerability remediation are actively maintained.

If you discover a security vulnerability:
1. Please open an issue on GitHub with details or reproduction steps.
2. Alternatively, report it privately via GitHub Security Advisories.
3. Automated fixes and patches will be reviewed and deployed promptly.

Thank you for helping keep this project secure!
